# Coolify project access

This repository builds OpenWrt router packages via GitHub Actions. The live Coolify inventory on 2026-11-26 did not identify an application bound to this repository. Do not copy the infrastructure API token, VPS SSH keys or production deployment credentials here. A new web service, package mirror or build worker would require an explicit deployment specification, a separate resource UUID and a resource-scoped token. Existing package build workflows are unchanged.
